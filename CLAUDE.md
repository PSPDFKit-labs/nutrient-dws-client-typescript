# CLAUDE.md

Canonical agent instructions for this repository live in @AGENTS.md — read it before
making changes.

The single highest-value rule, restated here so it survives even if the import above is
not expanded: **never hand-edit anything under `src/generated/`.** Those files are
generated by `npm run generate:types` / `npm run generate:types:extract` from the
vendored OpenAPI specs, and CI fails the build on any drift. See `AGENTS.md` for how to
change an API type correctly.
